# Bootcamp QI Tech 2026

Projeto desenvolvido durante o Bootcamp QI Tech 2026.

## Equipe

Matheus Silveira Feitosa, Rafael dos Santos Lombardi e Ryan de Oliveira Freitas.

Número do grupo: 34

## Projeto

O projeto consiste em uma API bancária para cadastro de clientes e contas,
transferências internas, envio PIX/TED para outro banco, emissão e pagamento
de boletos e consulta de extrato paginado.

A implementação principal está em [bootcamp-base-api](bootcamp-base-api/),
com instruções de execução, testes e endpoints no [README da API](bootcamp-base-api/README.md).

As decisões funcionais e arquiteturais da entrega estão documentadas no RFC
`RFC BANCO - Bootcamp QI Tech`.
